# DarkUniverse

![PHP](https://img.shields.io/badge/PHP-777BB4?style=for-the-badge&logo=php&logoColor=white)

Dark Universe - proyek website dengan tema gelap.


## Instalasi

```bash
# Clone repository
git clone https://github.com/AryaFatthurahman1/DarkUniverse.git
cd DarkUniverse

# Jalankan dengan PHP built-in server
php -S localhost:8000
```
